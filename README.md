# Claude Code ドキュメント検証シリーズ

Claude Code の公式ドキュメントに書かれていることが本当にそう動くのか、手元で確かめるためのキット集です。テーマごとに、誰でも同じ手順で試せるキットと、分かったことを1ページにまとめたページがあります。

## テーマの一覧

| テーマ | キット | まとめページ | 確かめたバージョン | 日付 | 結果 |
|---|---|---|---|---|---|
| 会話の要約（コンパクション）で何が残るか | [claude-compact-check](https://github.com/cookkawasaki/claude-compact-check) | [会話の要約と指示の残し方](https://claude.ai/artifact/Bu3uJXGuZNsvuvk4skSYF5) | 2.1.317 | 2026年11月 | 4件とも記述どおり（ドキュメントにない残り方が2つ） |

- 「結果」は、ドキュメントの記述どおりだったか、違ったかです。詳しくは各まとめページの「検証で分かったこと」にあります。
- 最初のテーマだけは、別のリポジトリにあります。手順はそのキットの README に従ってください。

## 試す人へ

1. **ターミナル:** 次を打ちます。

   ```bash
   git clone https://github.com/cookkawasaki/claude-code-verifications
   cd claude-code-verifications/topics/<テーマ名>
   ```

2. そのフォルダの `README.md` を、**人が**読んで進めます。README を Claude に読ませないでください（予想される結果が書いてあり、検証になりません）。

### 全部のテーマに共通の約束

- **`claude` は必ず `topics/<テーマ名>/` の中で起動します。** リポジトリの一番上やほかのフォルダで起動すると、テーマの設定が読み込まれず、結果が変わります。
- **前の検証の名残を消してから始めます。** Claude が自動で残すメモ（auto memory）は、このリポジトリの全テーマで共有されます。Claude Code の中で `/memory` を打ち、開いたメモに前の検証の合言葉などが残っていたら消して保存します。
- **許可を聞かれたら「Yes」（今回だけ）を選びます。** 「次から聞かない（don't ask again）」を選ぶと、その許可はリポジトリの一番上の `.claude/settings.local.json` に書かれ、ほかのテーマでも効いてしまいます。
- **変更の確かめと戻しは、テーマのフォルダの中だけで行います。** `git status .` と `git restore .` のように、最後に `.` を付けます。
